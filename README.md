# Hades · 微信小游戏 2D 俯视角动作 Roguelike

对标 Supergiant Games《Hades》的触屏 Roguelike，使用 **微信小游戏** 原生框架 + Canvas 2D（不依赖 WebGL）。

## 运行方式

1. 打开 **微信开发者工具**，选择 **新建/导入项目 → 项目类型「小游戏」**，目录选本仓库根目录。
2. 若提示 AppID，可选择「测试号」（项目已使用 `touristappid`）。
3. 编译运行，即可在模拟器或真机预览中体验。

> 渲染以 750 设计宽为基准，通过 `wx.getSystemInfoSync` 的 `pixelRatio` 等比缩放适配不同屏幕。

## 目录结构

```
game.js          小游戏入口：wx.createCanvas + 全局触摸/前后台 + 启动引擎
game.json        小游戏全局配置（竖屏等）
project.config.json  项目配置（compileType: game）
js/
  config.js   全局常量、配色、数值（集中管理便于扩展）
  utils.js    数学工具（clamp / lerp / damp 等）
  input.js    输入系统：左侧摇杆 + 右侧攻击/闪避按钮
  camera.js   镜头：平滑跟随 + 房间夹紧
  player.js   玩家：移动 / 普攻(扇形三连) / 闪避(无敌帧) / 受击
  enemy.js    近战追踪敌人：状态机 spawn→chase↔hurt→dead
  effects.js  打击特效（对象池）：挥砍/火花/飘字/消散/残影
  room.js       房间：被复用为单一竞技场（绘制地板/墙体）
  boons.js      祝福系统：神祇/祝福定义 + 可叠加的 BoonManager
  weapons.js    武器定义：剑/弓（改变普攻与特殊技）
  projectile.js 弹射物（弓箭）对象池
  engine.js     核心：画布/缩放/主循环/刷怪/武器/大招/战斗编排/渲染
```

## 已实现（第一步：项目骨架与基础移动）

- ✅ 小游戏入口 `game.js`：`wx.createCanvas()` 取上屏画布，`wx.onTouch*` 注册触摸。
- ✅ 主循环基于全局 `requestAnimationFrame`，采用**固定逻辑步长**（1/60）累加器，逻辑与渲染解耦。
- ✅ 高清屏适配：按设备像素比设置后备分辨率，以 750 设计宽等比缩放。
- ✅ 左侧**浮动虚拟摇杆**：左半屏按下即生成，驱动玩家全向（含八方向）移动，带死区与平滑加减速。
- ✅ 玩家以圆形表示（暗红渐变 + 金色描边 + 朝向指示 + 行走摆动 + 落地阴影）。
- ✅ **镜头平滑跟随**玩家，并限制在房间范围内。
- ✅ 美术基调：冥界深紫 / 岩浆橙 + 奥林匹斯金蓝（详见 `js/config.js` 的 `Palette`）。

## 已实现（第二步：战斗与敌人基础）

- ✅ **普通攻击**：右下角 ⚔ 按住即连击，前方**扇形判定**，三段连击（第三段更大更痛），命中有击退与受击硬直。
- ✅ **闪避**：» 按钮短距离位移 + **无敌帧**，消耗**体力**、带冷却；可取消攻击（dash-cancel）。
- ✅ **体力管理**：消耗后延迟回复，体力不足时闪避按钮变暗。
- ✅ **近战追踪敌人**：状态机 `spawn → chase ↔ hurt → dead`，跟随玩家、接触造成伤害（带冷却），可被击杀并消散。
- ✅ **血量显示**：玩家 HP/体力条（左上），敌人头顶受损血条。
- ✅ **打击反馈**：挥砍弧光、命中火花、飘字伤害、死亡消散、震屏（screen shake）——全部走 `effects.js` **对象池**。
- ✅ **死亡循环（最小版）**：阵亡弹出「你已陨落」遮罩，轻触重新开始（完整精华/殿堂在第六步）。
- ✅ **无限波次（临时）**：清场后数秒涌现新一波（门系统在第三步替换）。
- 🔹 ✦ 大招按钮为占位（第五步接入）。

## 已实现（第三步：房间系统与门）

- ✅ **网格化随机地牢**（`dungeon.js`）：从起始房随机生长 8~11 个房间，按相邻关系连门；BFS 距离决定 Boss 房（最远死胡同），并分配商店/精英房，其余为普通战斗房。
- ✅ **房间铺到世界空间**：房间按网格坐标摆放，之间以**走廊**相连；`room.js` 绘制带门缺口的墙体、按房型着色的地板与房型标记。
- ✅ **门禁逻辑**：战斗房进入即生成敌人并**锁门**（红色封印），清场后**门开启**（金色发光门槛）。
- ✅ **走到门 → 镜头平滑平移到相邻房间**：触发区检测 + 过门动画（玩家穿过走廊、镜头平滑跟随到新房间）。
- ✅ **小地图**（右上角）：显示已探明房间、类型配色、当前房高亮与连线。
- ✅ 死亡重开会**重新随机生成地牢**（完整精华/殿堂仍在第六步）。

## 已实现（第四步：祝福系统 God Boons）

- ✅ **数据驱动的祝福结构**（`boons.js`）：神祇 + 祝福定义 + `BoonManager`，新增祝福只需加一条定义并在 `recompute()` 描述聚合效果。
- ✅ **三选一选择界面**（Canvas 内绘制）：清场后弹出，神祇配色卡片 + 名称/槽位/描述（中文自动折行），轻触选择。
- ✅ **可叠加 / 升级**：重复获得同一祝福会升级（等级提升威力），左上角 Build 图标条显示已获祝福与等级。
- ✅ **五位神的实战效果**，在攻击碰撞/闪避时正确触发：
  - 宙斯·雷霆万钧：命中引发**连锁闪电**，向邻近敌人跳跃放电。
  - 波塞冬·惊涛裂岸：攻击**大幅击退** + 附加撞击伤害。
  - 阿瑞斯·血怒：命中施加**流血**（持续伤害，可独立击杀）。
  - 阿芙洛狄忒·魅惑：命中使敌人**虚弱**（降低其伤害）。
  - 雅典娜·神圣冲刺：**闪避无敌**时撞击敌人将其击退并造成伤害。
- ✅ 另含 3 项被动增益（最大生命/攻击力/最大体力），死亡重开时祝福清空（永久成长在第六步）。

## 设计调整：单一竞技场 + 不定时刷新精英/Boss

应需求改为**不进新房间，全程在一个放大约 5× 的竞技场**（3600×3200）作战；房间/门/小地图/过门系统已移除（`dungeon.js` 删除，`room.js` 复用为竞技场绘制）。

- ✅ **刷怪导演**（`engine.js`）：普通怪持续补充至上限；**精英怪**与 **Boss** 按随机间隔不定时刷新（精英 16~26s、Boss 45~70s，Boss 同时只存在一个）。
- ✅ **精英怪**：更大更肉、伤害更高、抗击退（橙色尖刺造型）。
- ✅ **Boss**：高血量、抗硬直，拥有**蓄力冲锋技能**（瞄准线预警 → 高速冲撞 → 硬直恢复）与**二阶段狂暴**（半血后更快、冷却更短）；屏幕顶部独立血条 + 降临警示。
- ✅ **击败精英/Boss 触发祝福三选一**（取代原“清场给祝福”），击败 Boss 额外回血。
- ✅ HUD 改为**存活时间 + 击杀数**；阵亡结算显示本局战绩，轻触重开。

> 所有节奏/数值（竞技场大小、刷怪间隔与上限、精英/Boss 属性与技能）集中在 `js/config.js` 的 `arena` / `spawn` / `enemy` 中可调。

## 已实现（第五步：武器、特殊技、神怒大招）

- ✅ **开局武器选择**界面（Canvas 内绘制）：**剑**（近战扇形三连）/ **弓**（远程速射），普攻方式明显不同。
- ✅ **自动攻击**：剑在敌人靠近时自动挥砍、弓自动瞄准最近敌人射击（按住 ⚔ 仍可朝摇杆方向手动攻击）；玩家移动不再上下晃动。
- ✅ **弹射物系统**（`projectile.js`，对象池）：弓箭飞行、撞墙/命中销毁，命中同样吃祝福加成。
- ✅ **武器特殊技**（✦ 按钮，带冷却）：剑·**旋斩**（环身范围斩击击退）/ 弓·**散射**（扇形齐射多箭）。
- ✅ **神怒大招**（⚡ 按钮）：命中/受击积攒**能量**，满槽释放**全屏冲击波**（重创周围敌人 + 闪屏 + 强震屏 + 短暂无敌）。
- ✅ HUD 增加**能量槽**与四个动作按钮（⚔ 普攻 / » 闪避 / ✦ 特殊 / ⚡ 神怒，含冷却/能量指示环）。
- ✅ 死亡重开会**重新选择武器**。
